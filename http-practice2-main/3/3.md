# Задание 3. Разбор WebSocket-кадра

## Структура кадра

WebSocket-кадр состоит из нескольких частей:

- **Opcode** — показывает тип сообщения:
  - `0x1` — текст
  - `0x2` — бинарные данные
  - `0x8` — закрытие соединения
  - `0x9` — Ping
  - `0xA` — Pong
- **Mask** — маска, которая используется для скрытия данных при передаче от клиента к серверу.
- **Payload** — само сообщение, например `Hello`.

## Пример

Отправляем сообщение `Hi`.

Кадр может выглядеть так:

```text
81 82 01 02 03 04 49 6B
```

Разбор:

- `81` — текстовое сообщение, последний кадр.
- `82` — данные замаскированы, длина 2 байта.
- `01 02 03 04` — маска.
- `49 6B` — замаскированное сообщение.

После снятия маски получаем `Hi`.
